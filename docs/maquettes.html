01 · Choix techniques

Une seule base TypeScript, un serveur qui fait autorité

Le moteur de règles est une bibliothèque pure, partagée entre le serveur (qui arbitre) et le client (qui surligne les coups jouables). Aucun joueur ne reçoit la main des autres : le serveur envoie à chacun une vue filtrée.

LangageTypeScript partout

Monorepo pnpm : engine, server, web. Types des messages partagés.

Moteur de règlesTS pur + Vitest

Machine à états déterministe (graine de mélange), un test par règle du PDF.

Temps réelNode 22 + Socket.IO

Salons, reconnexion automatique après coupure, horloge de tour côté serveur.

FrontReact + Vite

Zustand pour l'état, Framer Motion pour la donne, les poses et le ramassage.

DonnéesEn mémoire, sans compte

Pseudo + code de salon. Le salon retient le durak précédent pour la revanche.

Déploiement1 conteneur Docker

Le serveur Node sert aussi le front buildé. Fly.io, Render ou ton VPS.

navigateur (React)                      serveur Node (Socket.IO)
 ├─ rend la vue filtrée          ◄────   état complet de la partie
 ├─ surligne coups légaux (engine)        ├─ engine.apply(action) → valide / refuse
 └─ envoie une intention  ───────────►    ├─ diffuse une vue par joueur (mains cachées)
    {type:"defend", card:"J♠", on:1}      └─ minuteur de tour, reconnexion

Pourquoi pas autre chose

  • Colyseus : bon framework de jeu, mais ajoute une couche de schéma pour un jeu dont l'état tient en quelques Ko.
  • Firebase / Supabase : la logique d'arbitrage devrait vivre côté client ou en fonctions — plus facile de tricher.
  • Pixi / canvas : inutile, 36 cartes en DOM + CSS s'animent très bien et restent accessibles.

Ce qui est inclus en v1

  • Créer un salon ou en rejoindre un avec son code, 2 à 6 places.
  • Minuteur de tour (30 s, configurable), reconnexion, revanche.
  • Interface responsive : ordinateur et mobile, glisser-déposer + clic.

Prévu en V2

  • Bots pour compléter une table ou s'entraîner seul.
  • Comptes et stats : historique des parties, nombre de fois durak (ajoute Postgres).
  • Matchmaking public : file d'attente pour jouer avec des inconnus.
02 · Règles implémentées

Le PDF, traduit en règles de moteur

Clair appliqué tel quel. Tranché le PDF laissait une ambiguïté, la lecture retenue est indiquée.

Paquet & donne
Clair36 cartes (6 → As), 6 cartes par joueur distribuées 2 par 2. La carte suivante est retournée sous le talon : sa couleur est l'atout.
Premier défenseur
ClairLe durak de la partie précédente, sinon le joueur ayant l'atout le plus faible. Il choisit lequel de ses deux voisins l'attaque (écran dédié ci-dessous).
Défense
ClairMême couleur et rang supérieur, ou n'importe quel atout sur une non-atout. Atout sur atout : rang supérieur uniquement.
Attaque une par une
ClairUne carte est posée, le défenseur la bat, puis on relance. Jamais plusieurs cartes attaquantes en attente à la fois.
Relance
TranchéLe PDF dit : même valeur que l'une des deux cartes qui viennent d'être posées. Lecture stricte retenue : seules la dernière attaque et sa défense comptent, pas tout le tapis (la variante classique autorise toute valeur présente sur la table).
Qui relance
ClairL'attaquant d'abord ; s'il passe, les autres joueurs (sauf le défenseur) peuvent relancer dans l'ordre de la table.
Fin du pli
Clair6 attaques contrées, ou plus personne ne relance → défausse. Le défenseur ne peut ou ne veut pas battre → il ramasse toutes les cartes en jeu.
Ajout de bon sens : on ne relance pas si le défenseur n'a plus de carte en main.
Carte jouée 3 fois
Tranché« Une même carte ne peut pas être posée 3 fois d'affilée. » Lecture retenue : une carte posée en attaque lors de 2 plis consécutifs (car ramassée entre-temps) ne peut pas ouvrir/relancer au 3ᵉ pli consécutif.
Pioche
ClairRetour à 6 cartes : attaquant → autres joueurs dans l'ordre → défenseur, seulement s'il a tout battu. L'atout retourné est la dernière carte piochée.
Tour suivant
Tranché« Le prochain attaquant est le voisin du dernier attaquant, du côté opposé au défenseur. » Lecture retenue : il attaque le dernier attaquant — le jeu tourne toujours dans le même sens, quelle que soit l'issue du pli. À 2 joueurs, les rôles s'inversent à chaque pli.
Fin de partie
ClairTalon vide → on joue avec ce qu'on a. Main vide = sorti (on le saute dans la rotation). Le dernier avec des cartes est le durak.
Si les deux derniers se vident sur le même pli : pas de durak, égalité.
03 · Maquettes

Un tapis vert-bleu, des cartes ivoire, l'or pour ce qui est jouable

Direction : une table de cuisine soviétique devenue salon de jeu — feutre sarcelle profond, dos de cartes rouge laqué, accents laiton. Le doré ne sert qu'à une chose : montrer ce que tu peux faire maintenant.
